# Морской бой на Python + PyGame

Учебная компьютерная игра «Морской бой», выполненная в качестве учебного проекта студентом вуза "ГУАП" Молькова В.В.

## Возможности

- Игра против компьютера.
- Игра двух игроков за одним компьютером.
- Три уровня сложности компьютера:
  - лёгкий — случайные выстрелы;
  - средний — поиск кораблей в шахматном порядке;
  - сложный — после попадания проверяет соседние клетки.
- Автоматическая расстановка стандартного набора из 10 кораблей.
- Проверка попаданий, промахов, повторных выстрелов и победы.
- Счётчик уничтоженных кораблей обеих сторон.
- Раздел прогресса: число завершённых игр против компьютера и число побед игрока. Статистика сохраняется между запусками программы.
- Поля игроков скрыты в режиме двух игроков: корабли видит только тот, чей сейчас ход.

## Технологии

- Python 3
- PyGame 2
- Модуль `random` из стандартной библиотеки Python

## Запуск

1. Установите Python 3.10 или новее.
2. Откройте терминал в папке проекта.
3. Установите библиотеку командой:

   py -m pip install pygame

4. Запустите игру:

   python Battleship_code

## Правила

Перед началом игры автоматически расставляется классический набор: один четырёхпалубный, два трёхпалубных, три двухпалубных и четыре однопалубных корабля. Корабли не соприкасаются друг с другом даже по диагонали.

В свой ход игрок нажимает левой кнопкой мыши на клетку правого поля. Попадание даёт ещё один ход, а промах передаёт ход сопернику. Побеждает тот, кто первым уничтожит все корабли противника.
